# 按键与捏合（产品布局）

外壳约 **180mm** 竖握：

| 位置 | 按键 |
| --- | --- |
| **左侧面** | **PTT**（按住说话） |
| **右侧面** | **音量 + / −** |
| 正面上排 | **F4 · F5 · F6** |
| 正面中部 | **方向键 + 中心 OK** |
| 正面中排 | **Home · 返回 · 菜单** |
| 正面下排 | **F1 · F2 · F3** |

电气上正面键与音量键走 **4×5 矩阵**；PTT 独立 GPIO。捏合是固件识别的虚拟键。

## 接线（ESP32-C3）

### PTT

| 功能 | GPIO |
| --- | --- |
| PTT | **3**（接 GND = 按下） |

### 矩阵行 / 列

| 行 | GPIO | 列 | GPIO |
| --- | --- | --- | --- |
| ROW0 | **4** | COL0 | **0** |
| ROW1 | **5** | COL1 | **21** |
| ROW2 | **6** | COL2 | **11** |
| ROW3 | **7** | COL3 | **12** |
|  |  | COL4 | **13** |

### 矩阵 → 逻辑 ID

|  | COL0 | COL1 | COL2 | COL3 | COL4 |
| --- | --- | --- | --- | --- | --- |
| ROW0 | ↑ `1` | ← `3` | → `4` | ↓ `2` | OK `5` |
| ROW1 | Home `9` | Back `8` | Menu `10` | Vol+ `6` | Vol− `7` |
| ROW2 | F4 `14` | F5 `15` | F6 `16` | — | — |
| ROW3 | F1 `11` | F2 `12` | F3 `13` | — | — |

## 捏合手势（虚拟键）

同时按 **PTT + 音量** 时，固件约 150ms 内不会进入语音推流，改为发虚拟键事件：

| 手势 | 键 ID | 短按（单击）默认 | 长按（≥0.6s）默认 |
| --- | --- | --- | --- |
| PTT + Vol− | `17` | 全屏截图 `PrtSc` | 微信截图 `Alt+A` |
| PTT + Vol+ | `18` | 当前窗口截图 `Alt+PrtSc` | 系统截图工具 `Win+Shift+S` |

伴侣「按键映射」里可选中「捏− / 捏+」修改短按/长按动作。

## 其它默认（可改）

| 键 | 默认 |
| --- | --- |
| ←→↑↓ | 按住注入方向键（多任务里切换） |
| OK | 回车；长按 Agent 接受 |
| Menu | `Win+Tab` 多任务 |
| F1 / F2 / F3 | Agent 接受 / 拒绝 / 新建会话 |
| F4 / F5 | 打开 Cursor / Codex |

## 麦克风

I2S：BCLK=10，WS=20，DIN=2。见 [mic-inmp441.md](mic-inmp441.md)。
