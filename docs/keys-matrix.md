# 按键矩阵（ESP32-C3）

共 **17** 个物理键：独立 **PTT** + **16** 个矩阵键（方向/确认/音量/返回/Home/菜单 + F1–F6）。

IO 不够用逐键直连，因此采用 **4×5 矩阵**（占用 9 个 GPIO，预留 4 个矩阵位未用）。

## 接线

### PTT（独立）

| 功能 | GPIO | 说明 |
| --- | --- | --- |
| PTT | **3** | 接到 GND 为按下；按住说话 |

### 矩阵行（输出，空闲为高）

| 行 | GPIO |
| --- | --- |
| ROW0 | **4** |
| ROW1 | **5** |
| ROW2 | **6** |
| ROW3 | **7** |

### 矩阵列（输入，内部上拉）

| 列 | GPIO |
| --- | --- |
| COL0 | **0** |
| COL1 | **21** |
| COL2 | **11** |
| COL3 | **12** |
| COL4 | **13** |

每个按键接在「某一行 + 某一列」之间；按下时该列被拉低。

## 矩阵键位 → 逻辑 ID

|  | COL0 | COL1 | COL2 | COL3 | COL4 |
| --- | --- | --- | --- | --- | --- |
| ROW0 | ↑ `1` | ← `3` | → `4` | ↓ `2` | OK `5` |
| ROW1 | Vol+ `6` | Vol− `7` | Back `8` | Home `9` | Menu `10` |
| ROW2 | F1 `11` | F2 `12` | F3 `13` | F4 `14` | F5 `15` |
| ROW3 | F6 `16` | （备用） | （备用） | （备用） | （备用） |

## 默认伴侣映射（可改）

| 键 | 默认行为 |
| --- | --- |
| ↑↓←→ | 按住注入方向键（多任务视图里左右切换） |
| OK | 单击回车；长按 Agent 接受 |
| Menu / F6 | 多任务视图 `Win+Tab` |
| Back | Esc；长按 Agent 拒绝 |
| F1 | Agent 接受 `Ctrl+Enter` |
| F2 | Agent 拒绝 `Esc` |
| F3 | Agent 新建会话 `Ctrl+L`（Cursor） |
| F4 / F5 | 打开 Cursor / Codex(ChatGPT) |
| Vol± | 系统音量 |

典型流程：点 **Menu** 打开多任务 → **按住 ←/→** 切换窗口 → **OK** 确认；在 Cursor/Codex 里用 **F1/F2/F3** 接受、拒绝、新建会话。

## 与麦克风脚

I2S 仍为 BCLK=10、WS=20、DIN=2，与矩阵不冲突。触控板 I2C（8/9/1）预留，勿与矩阵复用。
